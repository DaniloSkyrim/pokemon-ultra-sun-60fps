# Pokémon Ultra Sun 60 FPS (Azahar)

60 FPS patch for **Pokémon Ultra Sun (v1.2 only)** on the **Azahar** emulator, for PC and Android. Game speed is unchanged.

**This mod was created with AI**. It was directed and tested in game by one person. This is an early test release.

Download and install instructions are in the [Releases](../../releases) page.

This is an unofficial fan project and is not affiliated with Nintendo, Game Freak or The Pokémon Company. It contains no game data.
